# Mac 測試清單：Moksa Web WebP 圖片轉換工具 v1.4.0

請找一台真的 Mac，照這份清單從上到下做一次。每一項通過就打勾 `[x]`，不通過就在後面寫看到什麼，最好附截圖（截圖快捷鍵：⌘＋shift＋4 框選，或 ⌘＋shift＋3 全螢幕，圖會存在桌面）。做完把這份清單和截圖一起交回。

CI 的 Mac 主機已經自動測過：視窗開得起來、字型、主題、拖放元件載入、轉檔結果都正確。這份清單要測的是 CI 做不到的部分：**第一次放行、真的用滑鼠拖檔案、在真實螢幕上看起來對不對**。

## 0. 測試環境（先填）

| 項目 | 填寫 |
|---|---|
| Mac 型號（蘋果選單 →「關於這台 Mac」） | |
| 晶片：Apple（M1／M2…）或 Intel | |
| macOS 版本（例如 14.6、15.1） | |
| 螢幕：筆電內建／外接，解析度 | |
| 下載的檔名（mac-arm64 或 mac-x86_64） | |
| 測試日期、測試人 | |

> 下載的檔案要跟晶片相符：Apple 晶片用 `mac-arm64`，Intel 用 `mac-x86_64`。如果另一種也方便測，兩種都測更好。

## 1. 安裝與第一次放行

- [ ] 1-1 用瀏覽器（Safari 或 Chrome）從 GitHub Release 下載 .dmg，**不要用隨身碟複製**（要模擬客戶的實際情況，這樣 macOS 才會加上「從網路下載」的標記）。
- [ ] 1-2 點兩下 .dmg 能打開，視窗裡看得到 App 圖示、「Applications」捷徑、「使用說明.txt」。
- [ ] 1-3 把 App 拖到 Applications，複製成功。
- [ ] 1-4 點兩下 `使用說明.txt` 能用「文字編輯」打開，中文正常、沒有亂碼。
- [ ] 1-5 第一次點兩下 App：記下跳出的視窗**原文**和截圖（預期是「無法打開」或「Apple 無法驗證…」；如果是「已損毀」也請記下來）。
- [ ] 1-6 照使用說明放行：
  - macOS 14 以前：試「按右鍵 → 打開」，記下有沒有出現「打開」按鈕。
  - macOS 15 以後：到「系統設定 → 隱私權與安全性」，記下有沒有出現「仍要打開」按鈕。
- [ ] 1-7 放行後 App 能開起來（從點兩下到出現視窗，大約幾秒：____ 秒）。
- [ ] 1-8 關掉 App 再點兩下開一次：**不再跳出警告**，直接開啟。
- [ ] 1-9 上方選單列顯示「Moksa Web Image Converter」，Dock 裡的圖示是 Moksa Web 的 logo（不是 Python 火箭或空白圖示）。

## 2. 畫面與字型

- [ ] 2-1 視窗大小合適，沒有超出螢幕，標題列和「開始轉換」按鈕都看得到。
- [ ] 2-1b 還沒加圖片時，左邊是一整塊虛線拖放區（上傳圖示、「＋ 加入檔案」「選擇資料夾」兩個按鈕、三步驟提示）。
- [ ] 2-2 頁首是深色底，左邊有 logo 和「Moksa Web」字樣，下方有一條橘紅色線。
- [ ] 2-3 「Moksa Web」字樣是幾何感的英文字（Space Grotesk），跟官網一致，不是一般的 Helvetica。
- [ ] 2-4 中文字清楚（蘋方），沒有方框（□）、問號、缺字。
- [ ] 2-5 字的大小正常：區塊名稱（① 用途與檔名、② 格式與品質…）不會小到看不清楚。
- [ ] 2-6 按鈕、下拉選單、勾選開關是橘紅色系（品牌主題），不是 Mac 預設的藍色；「格式」WebP／JPG／PNG 是分段按鈕，點了會切換。
- [ ] 2-6b 在輸入框選取文字時，反白是淡橘底、深色字（不是深橘底白字）。
- [ ] 2-6c 右上角深色「輸出摘要」會跟著設定變（換用途、改品質，摘要的格式、品質、尺寸、檔名都會變）。
- [ ] 2-6d 點「③ 尺寸」「④ 輸出位置」的標題可以展開、再點一次收起；收起時標題右邊有摘要文字。
- [ ] 2-7 右側設定欄：左邊的標籤（類別、用途、輸出格式…）沒有被切掉，和邊緣有一點距離。
- [ ] 2-8 Retina 螢幕上字和 logo 不會模糊（如果測試機是 Retina）。
- [ ] 2-9 把視窗拉小一點：右側設定欄出現捲軸，用觸控板兩指上下滑可以捲動，看得到「④ 輸出位置」；工具列按鈕放不下時會換到第二行，不會消失。
- [ ] 2-10 在設定欄上用觸控板捲動時，**滑過「品質」等數字欄或下拉選單，數值不會被改掉**。
- [ ] 2-11 點右上角「關於」：跳出深色的關於視窗，內容與 logo 正常；按「關閉」能關掉。
- [ ] 2-12（選做）系統設定改成「深色模式」後再開一次 App：畫面仍然是淺色主題、文字看得清楚。

## 3. 拖放（CI 測不到，這段最重要）

- [ ] 3-1 還沒有圖片時，從 Finder 拖**一張** JPG 到視窗：拖放區的虛線變成橘色實線、標題變「放開滑鼠，加入圖片」；放開後切換成清單＋預覽，清單有縮圖。
- [ ] 3-1b 已經有圖片時再拖一張進來：清單區出現淺橘色「放開滑鼠，加入圖片」提示，放開後加到清單最後。
- [ ] 3-2 一次拖**多張**（JPG、PNG 混合）：全部加入，順序正確。
- [ ] 3-3 拖**一個資料夾**：資料夾裡的圖片都加入。
- [ ] 3-4 拖進**檔名有中文和空白**的圖片（例如「產品 照片 01.jpg」）：能加入、能預覽、能轉檔。
- [ ] 3-5 拖進非圖片檔（例如 PDF、.txt）：不會當掉，也不會加入清單。
- [ ] 3-6 拖進來但不放開、又拖出去：橘色提示會消失，回到原本的樣子。
- [ ] 3-7 從桌面拖檔案（不是從 Finder 視窗）也可以。
- [ ] 3-8 按「＋ 加入檔案」「＋ 資料夾」：Mac 的選檔視窗正常出現，可以選取。

## 4. 轉檔與輸出

用自己的照片測，最好有一張直式、一張橫式、一張 PNG 透明圖。

- [ ] 4-1 類別選「電商 SKU 規範」→ 用途「商品圖（首圖＋特色圖）」，SKU 填 `TEST-001`，加 3 張圖：清單的輸出檔名顯示 `TEST-001pic`、`TEST-001pic1`、`TEST-001pic2`。
- [ ] 4-2 按「開始轉換」：底部出現進度條、「N / M 張 · 剩約 X 秒」和「停止」；清單「狀態」欄依序變成「轉換中…」→「✓ −xx%」。完成後底部寫出總共省了多少，右下角出現「開啟輸出資料夾」。
- [ ] 4-3 按「開啟輸出資料夾」：Finder 打開 `converted` 資料夾，裡面是 3 個 .webp。
- [ ] 4-4 在 Finder 選其中一個 .webp 按空白鍵預覽：圖片正常、2000×2000（⌘＋i 看尺寸）。
- [ ] 4-5 用途改「Slider 輪播」，放 1 張橫式圖：輸出 4 個檔（slider、sliderpc、slidertablet、slidermobile）。
- [ ] 4-6 類別「LINE 官方帳號」→「圖文選單 大」：輸出 3 個 JPG，檔名後面有尺寸（例如 `-2500x1686`）。
- [ ] 4-7 PNG 透明圖用「網站 WordPress → Logo（寬 600，透明 PNG）」：輸出仍然是透明背景。
- [ ] 4-8 點「④ 輸出位置」展開 → 選「自訂」→ 按「瀏覽…」選桌面：檔案存到桌面，④ 標題右邊顯示「Desktop」。
- [ ] 4-9 轉換中按「停止」：會停下來，不會當掉。
- [ ] 4-10 原始圖片都還在，沒有被覆蓋或刪掉。

## 5. 預覽

- [ ] 5-1 點清單中的圖：下方並排顯示「原圖」和「輸出結果」（左上角有小標籤），下面寫「原檔大小 → 輸出大小」和綠色的「−xx%」。
- [ ] 5-1b 底部列寫出「共 N 張 · 原始 … · 預估輸出約 …」。
- [ ] 5-2 改品質（例如 82 → 60）：預覽的檔案大小會跟著變。
- [ ] 5-3 打開「顯示安全區」：輸出圖上出現橘色虛線框。
- [ ] 5-4 點預覽圖：跳出放大視窗；按 esc 或點圖片可以關掉。
