Moksa Web WebP 圖片轉換工具 v1.4.1 使用說明（Mac 版）
==================================================

【這是什麼】
批次把 JPG / PNG / GIF / BMP / TIFF / WebP 圖片轉成 WebP、JPG 或 PNG，
選「用途」就自動套用尺寸、品質、檔案上限與檔名規則，轉換前可以即時預覽結果。
支援 macOS 12 以上。請下載跟電腦晶片相符的版本：
  ・Apple 晶片（M1、M2、M3、M4…）：檔名有「mac-arm64」
  ・Intel 晶片：檔名有「mac-x86_64」
  不確定是哪一種：點左上角蘋果選單 →「關於這台 Mac」，看「晶片」或「處理器」那一行。

【安裝】
1. 點兩下下載的 .dmg 檔，會打開一個視窗。
2. 把「Moksa Web Image Converter」圖示拖到旁邊的「Applications（應用程式）」資料夾。
3. 在 Finder 左側的「磁碟」或桌面上的磁碟圖示按「退出」，.dmg 就可以刪掉了。

【第一次開啟】（只有第一次要做）
這個 App 沒有向 Apple 付費申請簽章，所以第一次開啟時 macOS 會擋下來，請照下面的方法放行：

方法一：按右鍵打開（macOS 14 以前適用）
  1. 打開 Finder →「應用程式」，找到「Moksa Web Image Converter」。
  2. 在圖示上按右鍵（或按住 control 鍵再點一下）→ 選「打開」。
  3. 跳出的視窗再按一次「打開」。

方法二：到系統設定放行（macOS 15 以後一定要用這個方法；方法一沒有「打開」按鈕時也用這個）
  1. 先點兩下 App，會出現「無法打開」或「Apple 無法驗證…」的視窗，按「完成」或「好」關掉。
  2. 打開「系統設定」→ 左側「隱私權與安全性」→ 往下捲到「安全性」那一段。
  3. 會看到「已阻擋 Moksa Web Image Converter…」，按旁邊的「仍要打開」。
  4. 輸入電腦的登入密碼（或用 Touch ID），再按一次「仍要打開」。

放行一次之後，之後就能像一般 App 一樣直接點兩下開啟。
開啟要等 2～3 秒視窗才會出現，屬於正常現象。

如果出現「已損毀，無法打開。您應該將它丟到垃圾桶」：
  這是 macOS 對沒有簽章的 App 的提醒，不是檔案真的壞掉。請打開「終端機」（應用程式 → 工具程式），
  貼上下面這一行後按 return：
    xattr -dr com.apple.quarantine "/Applications/Moksa Web Image Converter.app"
  然後再用上面的方法一或方法二開啟。不確定的話，請聯絡 Moksa Web 協助。

【小螢幕筆電】
螢幕比較小時（例如 1366×768），右側設定欄會出現捲軸，用觸控板兩指往下捲就看得到每個步驟。
「③ 尺寸」「④ 輸出位置」平常收成一行，點標題才展開，所以通常不用捲動。
「開始轉換」按鈕固定在右下角，一定看得到。

【三步驟完成】
1. 加入圖片：把圖片或資料夾拖進視窗中間的虛線框，或按「＋ 加入檔案」「選擇資料夾」。
   加入後會出現清單（有縮圖）和預覽。清單順序就是流水號順序，
   可用清單上方的 ↑ ↓、排序按鈕調整，或在清單上按右鍵（觸控板兩指點按，或按住 control 再點一下）；按 delete（⌫） 鍵可移除選取的圖片。
2. 選類別與用途、填 SKU：右側「① 用途與檔名」先選「類別」（例如 Instagram、台灣電商平台），
   再選「用途」，格式、尺寸、品質、檔案上限、安全區與檔名規則會自動帶入。
   右上角深色的「輸出摘要」會寫出這次要輸出的格式、品質、尺寸、檔案上限與檔名；
   清單的「輸出檔名」欄也會即時顯示每張圖轉完的檔名。
3. 按右下角「開始轉換」。轉換時下方會出現進度條和剩餘時間，
   清單的「狀態」欄會顯示每張圖省了多少（例如 ✓ −76%）。
   完成後按右下角「開啟輸出資料夾」就能看到檔案。

【即時預覽】
點清單中的任一張圖，下方會並排顯示「原圖」與「輸出結果」（點預覽圖可以放大檢視），
並寫出「原檔大小 → 輸出大小」、節省比例（綠色）、實際尺寸、品質與檔名（是真的轉一次算出來的大小）。
改任何設定，預覽會自動更新；底部也會依預覽推估整批轉完大約多大。
「顯示安全區」：在輸出圖上畫出橘色虛線框，文字、價格、按鈕請放在框內。
  有平台規格的用途（例如 IG 限動、YouTube 橫幅、Google 廣告）會照平台實際被遮住的範圍畫；
  其他用途則顯示建議的中央 80%。
預覽下方出現紅色文字，代表需要注意（例如原圖太小被放大、檔案超過上限、轉完變大）。
切換到「轉換紀錄」可以看每個檔案的詳細結果；有略過或失敗時會自動切過去。

【常用用途說明】
■ 電商 SKU 規範｜商品圖（首圖＋特色圖）
  同一個商品的圖照順序放好（第 1 張是首圖），填 SKU，例如 ABC-001
  → ABC-001pic、ABC-001pic1、ABC-001pic2…
  WebP 品質 82、壓縮強度 6；縮放並補白邊成 2000×2000（商品不會被裁掉）

■ 電商 SKU 規範｜商品特色圖
  → ABC-001pic1、pic2…；只補特色圖時用，「起始號」填 3 就從 pic3 開始

■ 電商 SKU 規範｜銷售長圖
  → ABC-001sale1、sale2…；不調整尺寸
  （WebP 寬或高最多 16383 px，超過會自動等比縮小）

■ 電商 SKU 規範｜Slider 輪播（一次輸出 4 種尺寸）
  一次放一張 16:9 原圖，自動輸出：
    SKUslider        2560×1440（網站上傳用）
    SKUsliderpc      1920×1080
    SKUslidertablet  1200×675
    SKUslidermobile  800×450
  公告或活動 Slider：SKU 欄填「年份＋活動代稱」，例如 2025springsale
  WebP 品質 82、檔案上限 500 KB（超過自動降品質）；原圖不是 16:9 會置中裁切。
  ※ 手機直式 1080×1350（4:5）需要另外設計構圖：
    用途選「自訂」，尺寸選「裁成固定 寬×高」1080×1350。

■ LINE 官方帳號｜多頁訊息         1540×1000（1.54:1）JPG，10 MB 以下
■ LINE 官方帳號｜圖文訊息         1040×1040（1:1）JPG，10 MB 以下
■ LINE 官方帳號｜圖文訊息 高清    2080×2080（1:1）JPG，10 MB 以下
■ LINE 官方帳號｜圖文選單 大      一次輸出 2500×1686、1200×810、800×540，JPG，每張 1 MB 以下
■ LINE 官方帳號｜圖文選單 小      一次輸出 2500×843、1200×405、800×270，JPG，每張 1 MB 以下
■ LINE 官方帳號｜一般圖片訊息     寬 1024、長度不限，JPG，10 MB 以下
  LINE 只接受 JPG／PNG，所以這些用途會輸出 JPG（透明背景會補白）。
  檔名：「名稱」留空就沿用原檔名；有填名稱則為 名稱-1、名稱-2…
  圖文選單會在檔名後加尺寸，例如 menu-2500x1686.jpg。
  以上尺寸都是置中裁切填滿，重要內容請放在畫面中央。

■ 自訂｜保留原檔名、自訂｜名稱＋流水號
  格式、品質、尺寸全部自己設定。名稱＋流水號例如 banner-01、banner-02。

【更換版本】
圖片更換時，「更換版本」填 1 → 檔名後加 -1（例如 ABC-001pic1-1、ABC-001slider-1），
再換一次填 2 → -2。

【設定說明】
右側分成四個步驟，選好用途後大部分都已自動設定好，一般只要確認「① 用途與檔名」。
- ② 格式與品質
    格式：網站用 WebP；LINE 用 JPG；需要無損透明圖時用 PNG。
    品質：網站圖片建議 80～85（預設 82）；數字越高越清楚、檔案越大。
- ③ 尺寸（平常收起來，標題右邊會寫目前的尺寸；點標題可以展開修改）
    指定寬度／指定高度：等比縮放
    限制在 寬×高 之內：等比縮到框內，不裁切
    縮放並補白邊成 寬×高：不裁切，空白處補白（透明圖則補透明）
    裁成固定 寬×高：置中裁切填滿
    依百分比縮放、強制拉成 寬×高（會變形）
  預設不會把小圖放大；需要時勾「允許放大小圖」（會變糊）。
- ④ 輸出位置（平常收起來，點標題可以展開）
    預設存到原資料夾底下的「converted」資料夾；也可以選「原資料夾」，
    或選「自訂」再按「瀏覽…」選一個資料夾。
- 進階設定（按「▸ 進階設定」展開；用途已經設好，一般不用改）
    壓縮方式：請用「有損」。「無損」檔案會大好幾倍，只適合圖示或截圖。
    壓縮強度：0 最快、6 檔案最小（建議 6）。
    檔案上限 KB：超過時依序 ① 品質每次降 5、降到 60；② 尺寸不固定的用途（例如文章內文圖）
      每次縮小 10%，最多縮到一半；③ 仍超過再把品質降到 40。紀錄與預覽會寫出實際的品質與尺寸。
    透明度品質、保留 EXIF、轉完比原檔大就不保留、覆蓋已存在的輸出檔、加入資料夾時包含子資料夾。
- 原始檔一定會保留：輸出檔名就算跟原檔一樣，也不會覆蓋原檔。
- 設定會自動記住，下次開啟不用重設。
- 「開啟輸出資料夾」會用 Finder 打開轉好的檔案。

【常見問題】
Q：為什麼轉完反而變大？
A：原圖已經壓縮得很小時，用高品質重存會變大。品質調到 75～85，
   或在進階設定勾「轉完比原檔大就不保留」。

Q：預覽說「原圖較小，已放大」？
A：原圖比目標尺寸小，裁切類用途會放大填滿，畫面可能變糊，建議換更大的原圖。
